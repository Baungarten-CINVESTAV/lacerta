Lacerta GUI and FPGA Demonstration

This page summarizes the practical use of the Lacerta graphical interface design tool and shows how the generated HMI concepts can be implemented and evaluated on FPGA-based hardware. The objective is to document the full flow from interface creation in the Lacerta GUI to real execution on hardware, using a set of demonstration videos that illustrate both the user workflow and the resulting embedded display behavior.

The sequence of videos is organized to move from a quick introduction to the software environment, to a concrete hardware implementation example, to a second HMI demonstration, and finally to a more detailed explanation of the complete Lacerta functionality. Together, these materials help explain how Lacerta supports the design, export, and deployment of embedded human-machine interfaces.

Video 1. Quick Example of the Lacerta GUI

The first video presents a short demonstration of the Lacerta GUI. It gives an overview of the design environment and shows how graphical HMI elements can be arranged and edited inside the software.

YouTube link: Quick example of the Lacerta GUI

Video 2. FPGA Implementation of the HMI from Video 1

The second video shows the implementation of the HMI created in the first demonstration. Its purpose is to connect the GUI design stage with the actual hardware execution stage, showing how the interface behaves once deployed on the target platform.

YouTube link: Implementation of the HMI shown in Video 1

Video 3. Complete workflow of lacerta

The third video provides a second HMI example with the complete workflow of lacerta, illustrating the flexibility of the Lacerta approach for creating different interface layouts and display behaviors. This example complements the first demonstration by showing that the same workflow can be reused for additional interface styles and use cases.

YouTube link: Another HMI example

Video 4. Deep Explanation of Lacerta Functionality

The final video provides a more detailed explanation of the Lacerta platform and its overall functionality. It is intended as a more complete walkthrough of the architecture, software flow, and hardware behavior, helping the viewer understand how the different parts of the system work together.

YouTube link: Deep explanation of Lacerta functionality
